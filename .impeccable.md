## Design Context

### Users

Desktop keyboard users learning touch typing in a PC browser, with independently chosen Chinese/English interface and content languages.

### Binding reference

The user explicitly requires reproduction of the installed **KeyKey Typing Tutor**, not a new design inspired by it. Native practice, settings and statistics screenshots were captured on 2026-11-26 from `com.chekazuja.keykey-setapp`. Do not reinterpret the interface, invent sidebars/cards, add marketing copy, or apply a separate brand style.

### Visual direction

Charcoal full-window canvas, system sans-serif metrics, monospaced single practice line, outlined ISO keyboard, translucent hands directly over home keys, blue current letter/key/finger. Three metrics at the top, gear top-right, help/restart/statistics along the bottom. Right-side settings drawer with green switches and Automatic/Manual control. Statistics fills the window with a colored lesson ribbon, stars, speed bars above the baseline and typo bars below.

### Principles

- Match captured proportions, typography, colors and interaction placement before introducing any other visual changes.
- Only add the requested independent UI/content language controls, including Chinese pinyin/IME support, inside the existing settings pattern.
- Preserve accessibility and reliable local persistence without adding dashboard elements to the practice canvas.
- Use actual session data; the reference-style empty chart illustration must be noninteractive and semantically labeled as an illustration.

### First-use guidance

The user explicitly requested onboarding after reviewing the replica. Keep it within the existing dark/blue visual language: optional welcome/language choice, contextual F/J placement, then real exercise input. Keep the keyboard visible during placement, preserve user preferences and progress, and make replay available from Help.
