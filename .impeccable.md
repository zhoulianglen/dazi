## Design Context

### Users

Desktop keyboard users learning standard ten-finger touch typing in a PC browser. English and Chinese learners; UI locale and content language must be independent.

### Brand Personality

Calm, encouraging, precise. Retain DAZI branding. Emphasize patient skill development and confidence.

### Aesthetic Direction

User explicitly selected KeyKey Typing Tutor as the visual and product reference. A light, quiet native-app canvas, clear letterforms, generous white space, subtle dividers and blue active guidance. No dashboard clutter or game decorations.

### Design Principles

- Put practice text and correct finger placement first.
- Use color only to clarify active keys, fingers and learning progress.
- Prioritize accuracy and relaxed posture; never pretend to detect physical posture.
- Separate interface language, content language and Chinese input method.
- Keep all controls keyboard accessible, respect reduced motion and save progress locally.
